# slideio module

The entry points of the library: `slideio::openSlide()`, `slideio::getDriverIDs()` and the `slideio::Slide` and `slideio::Scene` classes. `slideio::makeScene()` builds a scene whose pixels the caller computes. Headers are included as `<slideio/slideio/...>`; linking `slideio::slideio` is enough.
