# Downloads

`slideio-converter` and `slideio-tiffinspector` ship with the C++ library
packages; there is no separate download. They need no programming and no
Python.

[Download the SlideIO library](https://github.com/Booritas/slideio/releases/latest)

| Platform | Where the tools are |
|---|---|
| Windows x86-64 | The `.zip` package, in its `bin` directory |
| macOS (Apple Silicon) | The `.tar.gz` package, in its `bin` directory |
| Linux x86-64 | The `.tar.gz` package, in its `bin` directory |
| Debian 12+ / Ubuntu 22.04+ | Their own package, `slideio-tools` |

How to install them is described under [Installation](index.md#installation).
