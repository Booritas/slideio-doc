# Keyboard and mouse reference

On macOS, press {kbd}`Cmd` wherever this page says {kbd}`Ctrl`.

The single-letter keys and the slide keys work only while the slide view has
keyboard focus; click the slide if they do nothing.

## Files

| Shortcut | Command |
|---|---|
| {kbd}`Ctrl+O` | File > Open Slide... |
| {kbd}`Ctrl+Shift+O` | File > Open DICOM Folder... |
| {kbd}`Ctrl+W` | File > Close |
| {kbd}`Alt+F4` | File > Exit (Windows and Linux) |

## View

| Shortcut | Command |
|---|---|
| {kbd}`Ctrl++` | Zoom In |
| {kbd}`Ctrl+-` | Zoom Out |
| {kbd}`Ctrl+0` | Fit to Window |
| {kbd}`Ctrl+1` | Actual Pixels |
| {kbd}`F11` | Full Screen |
| {kbd}`Ctrl+M` | Minimap |
| {kbd}`Ctrl+Shift+I` | Color Management |

## Panes

| Shortcut | Pane |
|---|---|
| {kbd}`Ctrl+Shift+C` | Channels |
| {kbd}`Ctrl+Shift+T` | Scenes |
| {kbd}`Ctrl+Shift+A` | Associated Images |
| {kbd}`Ctrl+Shift+P` | Properties |
| {kbd}`Ctrl+Shift+D` | Metadata |
| {kbd}`Ctrl+Shift+L` | Annotation List |
| {kbd}`Ctrl+Shift+E` | Annotation Properties |
| {kbd}`Ctrl+Shift+Y` | Layers |

## Tools

| Key | Tool |
|---|---|
| {kbd}`V` | Navigate |
| {kbd}`R` | Rectangle |
| {kbd}`E` | Ellipse |
| {kbd}`P` | Polygon |
| {kbd}`F` | Freehand Line |
| {kbd}`M` | Point Marker |
| {kbd}`A` | Arrow |
| {kbd}`T` | Text |
| {kbd}`L` | Ruler |
| {kbd}`G` | Angle |

## Editing

| Shortcut | Action |
|---|---|
| {kbd}`Ctrl+Z` | Undo; while drawing a polygon or line, remove the last point |
| {kbd}`Ctrl+Shift+Z`, {kbd}`Ctrl+Y` (Windows) | Redo |
| {kbd}`Delete` | Delete the selected annotation |
| {kbd}`Enter` | Finish a polygon or freehand line; keep typed text |
| {kbd}`Backspace` | Remove the last point of a polygon or freehand line being drawn |
| {kbd}`Esc` | Cancel the drawing or drag in progress; discard typed text; leave point editing |

## In the slide view

| Input | Action |
|---|---|
| Mouse wheel | Zoom at the pointer |
| Left drag (Navigate, on empty slide) | Pan |
| Middle drag, or {kbd}`Space` + left drag | Pan, with any tool |
| Arrow keys | Pan 20 pixels |
| {kbd}`+` / {kbd}`-` | Zoom in / out |
| Click (Navigate) | Select an annotation, or clear the selection |
| Drag an annotation (Navigate) | Move it |
| Drag a handle (Navigate) | Resize a rectangle or ellipse |
| Double-click a polygon or freehand line (Navigate) | Edit its points |
| Double-click a text (Navigate) | Edit its words |
| {kbd}`Ctrl` + click a point handle | Remove that point |

## While drawing

| Hold | With | Effect |
|---|---|---|
| {kbd}`Shift` | Rectangle, Ellipse | Square or circle |
| {kbd}`Alt` | Rectangle, Ellipse | Draw from the centre |

## In the panes

| Input | Where | Action |
|---|---|---|
| Click a row | Annotation List | Select the annotation |
| Double-click a row | Annotation List | Zoom to the annotation |
| {kbd}`Delete` | Annotation List | Delete the selected annotation |
| Double-click a name, {kbd}`F2` | Layers | Rename the layer |
| Click a thumbnail | Scenes | Open the scene |
| Click a thumbnail | Associated Images | Open the image in a window |
| Click or drag | Minimap | Centre the view there |
