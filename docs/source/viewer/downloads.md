# Downloads

Get the package for your platform from the latest release. The link points at
the current release, so it stays correct as new versions appear.

[Download SlideIO Viewer](https://github.com/Booritas/slideio-view/releases/latest)

| Platform | Package |
|---|---|
| Windows 10/11 (x86-64) | Installer (`.exe`) or portable archive (`.zip`) |
| macOS | Disk image (`.dmg`): `macos-arm64` for Apple Silicon, `macos-x86_64` for Intel |
| Debian 12+ / Ubuntu 22.04+ | Package (`.deb`) |
| Other Linux (x86-64) | Archive (`.tar.gz`) |

Everything the viewer needs, Qt included, ships inside the package. A graphics
card with OpenGL 3.3 support is required. How to install each package is
described under [Installation and setup](install.md).
